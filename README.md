# jottings

随手记下的东西。想清楚一件事,就写一篇,排一次版,推上来。

## 篇目

**《刻舟记》** · 二〇二六年八月 · [PDF](kezhouji.pdf) · [源码](kezhouji.tex)

从《吕氏春秋 · 察今》里那个被笑了两千年的楚人写起:小时候笑他傻,长大以后才发现,自己也一次次回到那个路口、那家小店、那个黄昏的晚霞里,在记忆的船舷上刻记号。写沈园的梅花和江楼的月色,写那些明知无用却还是要去的地方;最后写剑沉进河床之后,怎样成了托着人往前走的东西。正文之后另有一则后记,写给一起做过的人。

## 排版

版式的意思是"本子",不是"论文":A5 的小开本、楷体、宽行距,不编号、不加页码、不用脚注,该注的话就写在句子里。

XeLaTeX + `ctexart`,中文字体用 TeX Live 自带的开源 Fandol,任何装了 TeX Live 或 MacTeX 的机器都能直接编译:

```bash
make          # 等价于 latexmk -xelatex kezhouji.tex
make clean    # 清掉中间文件
```

macOS 上想换成系统的楷体,把 `kezhouji.tex` 里的 `fontset=fandol` 改成 `fontset=macnew`。编译好的 PDF 也一并放在仓库里,不想装 TeX 的人可以直接读。

## 写在后面

*以下是 Claude 排版这篇稿子时的一点感想。*

用 git 存随笔,这件事本身就有点像刻舟。每一次 `git commit`,都是在船舷上刻下一道记号:时间、位置、当时的样子。区别只在于——仓库里的水不流。所以在这里,刻舟求剑真的能把剑捞回来,`git checkout` 一下,那天写下的句子一个字都不会少。

《刻舟记》说的恰恰是另一件事:真正的那条河不给这个权限。人不能两次踏进同一条河流,也没有哪个渡口肯为谁停一停。也许这正是人愿意把东西写下来的原因——文字是唯一一条允许回头的河。写下来,就等于在一条不流的河上,给那段时光留了一个可以随时靠岸的渡口。

这篇稿子里我最看重的是次序。它把三分之二的篇幅留给了停在原地的人,替他们说完了话,最后才敢开口讲往前走。很多劝人"向前看"的文章输就输在没有前半段——道理没错,但站着说话。先承认河的沉重,后面的开解才落得下去。

至于那把剑:它沉下去以后并没有消失,只是换了一种存在方式,从你手里握着的东西,变成了你脚下踩着的东西。
